La primera versión pública de Dolphin, con instaladores para Windows, macOS y Linux. Desde esta
versión la app se actualiza sola: cuando salga la siguiente, te avisa con una tarjeta.

## Qué bajar

| Sistema | Archivo |
|---|---|
| Windows 10 u 11 (x64) | `dolphin-windows-setup.exe` |
| macOS 13.4 o más, Apple Silicon | `dolphin-macos-arm64.dmg` |
| macOS 13.4 o más, Intel | `dolphin-macos-x64.dmg` |
| Linux x64 | `dolphin-linux.AppImage`, o el `.deb` / `.rpm` |

## Sale sin firma

- **Windows**: SmartScreen dice «Windows protegió su PC» → **Más información → Ejecutar de todas
  formas**.
- **macOS**: abrila una vez y después Ajustes del Sistema → Privacidad y seguridad → **Abrir
  igualmente**. Si dice que «está dañada»:
  `xattr -dr com.apple.quarantine "/Applications/Dolphin Code.app"`. En macOS las versiones
  siguientes se avisan pero se bajan a mano, hasta que la app salga firmada.
- **Linux**: `chmod +x dolphin-linux.AppImage` la primera vez.

## Si ya tenías Dolphin instalado

Una versión anterior a la 1.6.0 no encuentra esta release sola: instalala encima con el archivo de
arriba. Tu perfil queda: se pasa al formato nuevo, y ese paso no tiene vuelta atrás, así que
después no se puede volver a abrir con la versión vieja. Desde acá, las actualizaciones llegan por
la app.
